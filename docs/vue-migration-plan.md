# Vue + Inertia + shadcn-vue migration plan

**Status:** Planned · 2026-09-25
**Decisions:** [ADR 0002](adr/0002-inertia-native-writes-json-only-for-chat.md) · vocabulary in [CONTEXT.md](../CONTEXT.md)

## Settled decisions

| Topic | Decision |
|---|---|
| Cutover | Incremental, one PR into `main` per slice. `main` stays shippable between slices. |
| Prerequisite | PR #21 (`user_query/embedding`) merges first. This branch rebases onto it. |
| Language | TypeScript, `<script setup lang="ts">`, Composition API. |
| Theme | shadcn-vue default **neutral**, dark-only (`class="dark"` on `<html>`). No raw hex colours. |
| Document writes | Inertia-native (`useForm` / `router`, redirects, shared `errors`). |
| Transition seam | `store` / `update` / `destroy` return JSON when `$request->expectsJson()`, otherwise redirect. Removed in Slice 4. |
| Opening a Document | Optional lazy `document` prop keyed by `?document=<slug>`, the same on Workshop and Search. |
| Chat query | The one sanctioned JSON endpoint, called through a typed fetch helper. |
| URLs in TS | `laravel/wayfinder`. |
| Delete confirm | shadcn `AlertDialog` (replaces `confirm()`). |
| Save/delete feedback | Silent, same as today. No toasts. |
| Search | Submit-only, `router.get(..., { preserveState: true, replace: true })`. |
| Origin badge | Label stays server-owned: send `Origin::label()` in the props. `badgeClasses()` (hex) is replaced by a shadcn `Badge` variant chosen in Vue. |
| Naming | "formulaire" is retired. The page is **Workshop**. `/formulaire` stays as a redirect only. |
| Backend | Barely changes: only controller return statements / prop shaping, the temporary seam, Inertia/Wayfinder wiring, redirects and tests. No changes to models, services, jobs, Form Requests, migrations, Resources or validation. |
| UI | Everything is shadcn-vue, per [COMPONENTS.md](../COMPONENTS.md). |
| Execution | [agentic-strategy.md](agentic-strategy.md): Opus `migration-planner` + 1 Sonnet `migration-implementer` per slice (2 in parallel for Slice 2 only). |
| Environment | Everything runs through **Laravel Sail** (`compose.yaml`: `laravel.test` on PHP 8.5, `pgsql` with pgvector, `ollama`). No host PHP, Composer, pnpm or Postgres. See [Environment](#environment-sail). |
| State | No Pinia. Page props + composables. |
| SSR | No. |
| Tests | Pest feature tests (`assertInertia` for pages) + an agent-browser smoke checklist per slice. No Vitest, no Pest browser plugin. |

## Environment (Sail)

### One-time bootstrap

`compose.yaml` builds from `vendor/laravel/sail/runtimes/8.5`, so `vendor/` must exist before the first `sail up`:

```shell
composer install --ignore-platform-reqs   # one-off with Herd's composer, only to create vendor/
```

Then in `.env`:

```dotenv
APP_PORT=8000            # compose maps ${APP_PORT:-80}; keeps APP_URL=http://localhost:8000 valid
DB_HOST=pgsql            # the compose service, not 127.0.0.1
```

```shell
alias sail='sh $([ -f sail ] && echo sail || echo vendor/bin/sail)'
sail up -d
sail composer install     # reinstall inside the PHP 8.5 container
sail pnpm install
sail artisan migrate
```

### Command mapping

Every command in this plan, the agent definitions and the handoffs runs through Sail:

| Instead of | Use |
|---|---|
| `php artisan …` | `sail artisan …` |
| `php artisan test --compact` | `sail artisan test --compact` |
| `vendor/bin/pint --dirty --format agent` | `sail pint --dirty --format agent` |
| `composer …` | `sail composer …` |
| `pnpm …` / `pnpm dlx …` | `sail pnpm …` / `sail pnpm dlx …` |
| `vue-tsc --noEmit` | `sail pnpm exec vue-tsc --noEmit` |
| `php artisan tinker` | `sail tinker` |

- Agents run `sail up -d` first if `sail ps` shows the containers are down, and never `sail down -v` (it wipes the pgsql volume).
- The Vite dev server runs in the container (`sail pnpm run dev`, port `VITE_PORT` 5173). If HMR doesn't reach the browser, fix it in Slice 1 via `vite.config` `server` options, using ctx7 docs for `laravel-vite-plugin`.
- agent-browser smoke tests hit `http://localhost:8000`.

## Slices

### Slice 0 — Characterisation tests

No behaviour changes. Pin down current HTTP behaviour so later slices can refactor safely.

- Complete the [Sail bootstrap](#one-time-bootstrap) first (`vendor/` is missing). Tests run against the Sail `pgsql` service, which is needed for full-text and vector search.
- Feature tests, using factories:
  - `GET /` redirects to `/formulaire`, which redirects to `/documents`. `GET /formulaire` redirects to `/documents`.
  - `GET /documents` lists Documents ordered by title.
  - `POST /documents` (JSON) creates the Document and its tags and returns 201 with the resource. Invalid input returns 422 with field errors.
  - Creating a Document whose slug is taken by a live **or deleted** Document is rejected.
  - `PUT /documents/{slug}` updates fields. The slug does not change when the title changes.
  - `DELETE /documents/{slug}` soft-deletes the Document, hard-deletes its Chunks and returns 204.
  - `GET /search?query=…` returns ranked Chunk matches. An empty query returns no results.
  - The chat query endpoint is already covered by PR #21's `MeaningSearchTest`. Extend it only if there are gaps.

**Done when:** all of the above pass and Pint is clean.

### Slice 1 — Infrastructure

No visible change: both pages are still Blade.

- Install the approved dependencies with `sail composer require …` and `sail pnpm add …`. Add `HandleInertiaRequests` middleware, the `app.blade.php` root view, `app.ts`, `tsconfig.json`, Vite `vue()` + Wayfinder plugins.
- `sail pnpm dlx shadcn-vue@latest init` with the neutral theme. Tailwind v4 tokens go in `app.css` (the existing Blade pages keep their classes until they are ported).
- `sail artisan boost:install` to generate the Inertia/Vue guidelines and skill.
- Create `.ai/rules/index.md` plus:
  - `frontend/inertia.md`: pages only in `pages/`, typed props, writes via `useForm` / `router`, the chat is the only `fetch`, Wayfinder for every URL, a `document` prop for opening Documents.
  - `frontend/shadcn.md`: `components/ui/` is CLI-owned and customised by wrapping, theme tokens only, no raw hex.
  - `testing/http.md`: `assertInertia` for page responses, a characterisation test before touching a controller.
- Add a `types/index.ts` mirroring `DocumentResource` and `ChunkResource`.

**Done when:** `sail pnpm run build` and `sail pnpm exec vue-tsc --noEmit` pass, `sail pnpm run dev` hot-reloads in the browser, all Slice 0 tests still pass (`sail artisan test --compact`), and both Blade pages behave the same (agent-browser smoke).

### Slice 2 — Workshop page

- `DocumentController@index` → `Inertia::render('Workshop', [...])` with `documents` and an optional lazy `document` (from `?document=`).
- Add the `expectsJson()` seam to `store` / `update` / `destroy` (JSON for the Blade Search page, redirect for Inertia).
- Build `AppLayout`, `DocumentSidebar`, `IngestDialog`, `DocumentDialog` (edit toggle, word count, `AlertDialog` delete), `ChatPanel` (ported from #21's `chat.js`: user bubble, pending state, Chunk match cards with similarity/distance, click opens the Document).
- Update the tests: index uses `assertInertia`, and writes are tested both with a JSON `Accept` header and as Inertia requests.

**Smoke:** list → open Document → edit → save → delete (confirm) → create via ingest → validation errors shown → chat query returns Chunk matches → clicking a match opens the Document → deep link `/documents?document=<slug>` opens the modal → Back closes it.

### Slice 3 — Search page

- `FullSearchTextController@index` → `Inertia::render('Search', [...])` with `query`, `results` (Chunk matches) and `documents` for the sidebar, plus the lazy `document` prop.
- `Search.vue` reuses `AppLayout` and the dialogs. Submit uses `router.get` with `preserveState` + `replace`.
- Deleting from Search refreshes the results (a partial reload of `results` and `documents`).

**Smoke:** search → result count and ranks shown → open result → edit/delete from Search → results update → shareable `/search?query=…` URL.

### Slice 4 — Cleanup

- Delete `resources/views/formulaire.blade.php`, `search.blade.php`, `components/`, `welcome.blade.php`, `resources/js/app.js`, `resources/js/formulaire/`.
- Remove the `expectsJson()` branches, the JSON-only tests and `DocumentResource` if it is no longer used (the chat still uses `ChunkResource`).
- Keep `/formulaire` → `/documents` as a redirect only. Point `/` straight at `/documents` and update the Slice 0 redirect test to match.
- Mark ADR 0002 as fully applied.

**Done when:** `grep -r formulaire resources app` only hits the redirect, all tests pass, `vue-tsc` and Pint are clean, and a full agent-browser smoke pass of Slices 2 and 3 succeeds.
